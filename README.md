## ⚡ Visão Geral

A internet abriga uma quantidade incomensurável de conhecimento, cultura, entretenimento e ferramentas livres. Contudo, esses dados costumam estar dispersos em fóruns restritos, canais arquivados, repositórios independentes ou segregados por barreiras linguísticas.

A **Megathread Pirata** (desenvolvida sob o codinome de projeto *Nakayama Festa*) centraliza, audita e organiza as melhores fontes da rede em uma interface moderna, rápida e categorizada, fundamentada em quatro pilares:

- **100% Livre e Gratuita:** Zero anúncios comerciais, zero rastreadores invasivos, sem encurtadores monetizados ou links de afiliados.
- **Deduplicação e Curadoria Rígida:** Mais de **770+ links ativos** testados e auditados, filtrados contra malware e serviços predatórios.
- **Sinalização Linguística:** Identificação imediata do idioma de destino (`[PT-BR]`, `[GLOBAL]`, `[EN]`, `[ES]`).
- **OpSec e Privacidade:** Recomendações e tutoriais práticos sobre como navegar, baixar e automatizar fluxos locais com segurança.

## ✨ Recursos da Interface

O projeto foi estruturado com ferramentas integradas para facilitar a navegação cotidiana e a preservação independente do acervo:

- 📥 **Exportação de Favoritos (Netscape Bookmark HTML):**
  - **Exportar Tudo:** Na página inicial, baixe um arquivo `.html` contendo todos os 770+ links estruturados em pastas temáticas, compatível com qualquer navegador (Firefox, Brave, Chrome, Edge, Safari).
  - **Exportar por Categoria:** Exporte apenas os recursos visíveis ou filtrados dentro de cada biblioteca específica.
- ⚠️ **Reportar Link Quebrado:**
  - Botão dedicado em cada card e linha de tabela para abrir diretamente uma *Issue* pré-formatada no GitHub com os dados do recurso, viabilizando manutenção comunitária ágil.
- ⌨️ **Atalhos Rápidos de Teclado:**
  - Tecla `/`: Foca imediatamente no campo de busca global.
  - Tecla `Esc`: Limpa os filtros ativos e restaura a listagem completa.
- 🎛️ **Alternância de Visualização (Cards / Tabela):**
  - Alterne entre visualização em grade com detalhes expandidos (*estilo TheIndex*) ou tabela compacta de alta densidade de dados (*estilo EverythingMoe*).
- 🔝 **Retorno Rápido:**
  - Botão flutuante para retorno suave ao topo em listagens extensas.

## 🛡️ Regras Fundamentais de Segurança Digital (OpSec)

Práticas recomendadas para navegação e preservação local:

1. **Extensão Indispensável:** Nunca navegue em índices livres sem o [**uBlock Origin**](https://ublockorigin.com/). Ele neutraliza scripts invasivos, pop-ups maliciosos e redirecionamentos indesejados.
2. **Proteção de Rede (VPN / DNS):** Para transferências P2P/BitTorrent, priorize VPNs sem registro de logs auditadas ([Mullvad](https://mullvad.net/) ou [Proton VPN](https://protonvpn.com/)) ou resolução de DNS criptografada via DoH/DoT ([Quad9](https://quad9.net/) ou [NextDNS](https://nextdns.io/)).
3. **Higienização de Arquivos:** Nunca execute binários (`.exe`, `.scr`, `.bat`) obtidos em diretórios de streaming ou documentos de texto suspeitos. Em caso de dúvida, analise o arquivo no [VirusTotal](https://www.virustotal.com/) ou isole a execução via [Dangerzone](https://dangerzone.rocks/).

## 🚀 Execução Local do Projeto

Para executar a documentação em máquina local via VitePress com hot-reload ativo:

```bash
# 1. Clonar o repositório
git clone https://github.com/Apfelstrudelzinho/nakayama-festa.git
cd nakayama-festa

# 2. Instalar dependências
npm install

# 3. Executar o servidor de desenvolvimento
npm run docs:dev
```

Abra a URL indicada no seu terminal para explorar a megathread.

Para compilar os arquivos estáticos de produção:
```bash
npm run docs:build
```
